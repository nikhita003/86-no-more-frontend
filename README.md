# 86 No More – Frontend (Smart Restaurant Interface)

## Overview
86 No More is a full-stack restaurant management system designed to reduce food waste and prevent inventory shortages. This repository contains the **frontend application**, providing an interactive interface for both customers and restaurant staff.

The system dynamically updates menus based on ingredient availability, improving operational efficiency and enhancing user experience.

---

## Key Features

### User Experience & Interface
- Responsive UI for seamless navigation
- Dual-purpose interface for customers and restaurant staff
- Real-time updates on menu availability

### Core Functionalities
- User authentication (Login/Register)
- Menu browsing and ordering interface
- Inventory visibility for staff
- Customer feedback and rating system
- Data visualization for inventory insights
